# Tell Me Everything!

A local website. The replies are written lines in `data/responses.json`, not a live AI model.

## Try it

From this folder:

```bash
python3 -m http.server 8000
```

Open http://localhost:8000

Opening `index.html` by double-clicking it will not load the replies. The browser blocks that. The command above only serves these files.
